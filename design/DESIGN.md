# neoui design: "Belle, modernized"

neoui keeps the structure people knew on Nokia Belle:
- a thin status bar;
- a 3-column app menu;
- a graphite bottom toolbar with back, search and options;
- a black canvas.

It updates the look: softer contrast, rounder shapes, one icon style, more air and smooth motion.

**What is reused, and what is not**
- **Reused:** only *facts*: sizes, proportions, colour values and timings. They come from two places:
  - the Symbian^3 open-source release (EPL-1.0) layout data;
  - measurements of screenshots of a real N8 running Belle Refresh.
- **Not reused:** no Nokia artwork, icon, font or file is copied.
  - Every icon in `ui/icons/` is original, generated by `tools/make_icons.py`.
  - The font is Inter (OFL).
  - The raw reference material stays in the workspace's private, never-committed `private/` folder.

## Units
**1 dp = min(window width, window height) / 360.** The reference screen is 360x640, so:
- the Pixel 3a XL (1080x2160) has 3 px per dp;
- Syborg (768x640) has 1.78 px per dp.

`ui/launcher.slint` computes it and sets `Theme.dp`.

## Tokens (`ui/theme.slint`)

| Token | Value | Source |
|---|---|---|
| `status-h` | 25 dp | EPL layout: `area_top_pane` variety 1, the thin status pane (`measured.json`). |
| `toolbar-h` | 61 dp | EPL layout: `area_bottom_pane` / `control_pane`. The Belle screenshot shows the same: the toolbar starts at y=580 of 640. |
| `toolbar-button-w` | 116 dp | EPL layout: `cell_toolbar2_fixed_pane` (3 buttons across 360). |
| `app-row-h` | 135 dp | Belle screenshot: app menu row pitch. |
| `app-icon` | 72 dp | Belle screenshot: the icon is about 76 dp. Modernized: slightly smaller, with more space around it. |
| `list-row-h` / `list-row-double-h` | 56 / 72 dp | EPL layout: single row 42, double row 52 (`list_single_pane`, `list_double_pane`). Modernized: raised to current touch-target sizes. |
| `font-status`, `font-label`, `font-body`, `font-title` | 13 / 13.5 / 16 / 19 dp | EPL `Cdlfontinst_qhd_touch.cpp` text panes: secondary 32, primary 42, title 41 px. The Belle screenshot puts labels at about 17 px. Modernized: lighter and smaller with Inter. |
| `bg` | `#000000` | Belle screenshot: canvas and status bar. |
| `toolbar-top` → `toolbar-bottom` | `#2a2a2c` → `#0f0f10` | Belle screenshot: the toolbar gradient runs from #2a2a2a to #0f0f0f. |
| `text`, `text-secondary`, `text-dim` | white, `#b9bec7`, `#7d838c` | Modernized: softened greys for secondary text. |
| `accent` | `#3d8bfd` | neoui's own. |
| `open` / `close` / `popup` / `page` / `fast` | 250 / 300 / 250 / 350 / 150 ms, out-quad | Belle's transition effects: app start 0.25 s, app exit 0.3 s, pop-ups 0.25 s, options menu 0.3 s, home page switch 0.35 s; most curves linear or out-quad (median appear effect 0.225 s over 61 effects). |
| `title-h`, `avatar`, `section-h`, `tab-h`, `key-h`, `dock-h`, `card-*`, `field-h` | 52 / 44 / 34 / 46 / 66 / 92 dp, card radius 14 | Modernized component sizes built on the measured frame. They will be checked against the Belle screen catalogue. |

`design/measured.json` is the raw output of `tools/extract_design.py`. It holds every measured rectangle, with its layout component and variety, at 360x640 in portrait and landscape.

## Icons (`ui/icons/`, generated by `tools/make_icons.py`)
- **One grid and one weight:** a 24-unit grid with 1.8-unit strokes, round caps and round joins.
- **`sys/`:** white glyphs, tinted in Slint with `colorize`. There are 26: the toolbar (back, search, options, home, close, add, edit, delete, call, end call) and the status indicators (signal, wifi, battery, charging, bluetooth, alarm, bell, silent, message, missed call, headset, location, usb, lock, vibrate, data).
- **`apps/`:** the glyph on a rounded tile (radius 26 of 96) with a top-lit gradient and a faint inner rim. There are 12: phone, messages, contacts, browser, camera, photos, music, calendar, clock, files, settings, terminal.
- **Rasterisation:** Slint draws each SVG at build time at its `width`/`height`, which is 96 px for `sys` and 192 px for `apps`.

## Display digits (`ui/icons/digits/`)
SDF text breaks up at clock sizes (about 200 px), so the large clocks use `BigClock` (`components/controls.slint`). It is built from our own display digits: a light geometric face on a 14×24 grid with the same stroke and caps as the icons, generated by `tools/make_icons.py`.

## Components (`ui/components/`)
- `frame.slint`: `StatusBar` (title, indicators, clock; tap = notification shade), `Toolbar` (back · optional action · Options), `TitleBar`, `Glyph`.
- `lists.slint`: `ListRow` (icon or avatar, one or two lines, value / unread dot / switch / chevron), `SectionHeader`, `Avatar` (initials on a solid colour; the software renderer cannot round a gradient), `Switch`.
- `controls.slint`: `Button`, `RoundButton`, `SearchField`, `TabBar`, `Slider`, `Card`, `PageDots`, `OptionsMenu` (Belle's Options sheet rising above the toolbar), `BigClock`.
- `shade.slint`: the notification shade (quick toggles, brightness, notifications).

## Screens (`ui/screens/`, run by `ui/shell.slint`)
The shell keeps `screen` (an app, `home` or `menu`) and `view` (a sub-view; `""` is the app's main view). Back closes an overlay, then leaves the sub-view, then returns to where the app was opened from. Screen changes fade and rise in with `open` (0.25 s).

| Screen | Views |
|---|---|
| home | clock + date, today card, favourites, music card; 3 swipeable pages; dock (Phone, Messages, Apps, Browser, Camera); a landscape layout |
| menu | 3/4-column scrolling app grid |
| phone | keypad, recent calls (`log`), in call (`call`) |
| messages | conversation list, thread (`thread`) with composer |
| contacts | favourites + all, contact card (`card`) |
| browser | start page, page (`page`) |
| camera | viewfinder, photo/video, shutter |
| photos | grid, photo (`photo`) |
| music | library tabs + mini player, now playing (`playing`) |
| calendar | month + today, day (`day`) |
| clock | clock face, alarms, world (tabs) |
| files | drives, folder (`folder`) |
| settings | grouped list, `connectivity`, `display`, `about` |
| terminal | console with an extra-keys row (Ubuntu Mono, UFL) |

All the sample data (`ui/data.slint`) is invented. Phone numbers use the fictional 555-01xx range.

`cargo run -p neoui-host -- --screen settings/display` opens a screen directly.

## Regenerating
```sh
python3 tools/extract_design.py --ref ../private   # facts -> design/measured.json (needs the private EPL inputs)
python3 tools/make_icons.py                         # icons -> ui/icons/
cargo test                                          # re-renders snapshots/
```
